# RKA Windows Companion v1.3.0

Ships inside RKA Client & Companion Setup 1.1.0; PCs with the Setup's update task install it by themselves.

## What's new

- **Lock on Ctrl+Alt+Del**, a new Guest lockdown row: Block takes Lock off Ctrl+Alt+Del and Windows+L for the guest, so nobody leaves the PC on the lock screen. Sign out and Switch user stay on Ctrl+Alt+Del: Windows doesn't let any program block or change Ctrl+Alt+Del itself, and those two are the staff way out. Unlock everything allows it again.
- **Help has a Steam checklist** for each PC: schedule Steam's game updates for after closing time, and allow game file transfers over the local network so one PC's download feeds the others. It's done once by hand in Steam's settings; the Companion doesn't edit Steam's own files, which Steam rewrites while it runs.

## Upgrading

Install RKA Client & Companion Setup 1.1.0, or let the update task do it. The agent upgrades at the same time; then set the newest agent version (1.3.0) in Lovable.
