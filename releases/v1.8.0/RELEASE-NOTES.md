# RKA Windows Companion v1.8.0

Goes with Control Room 0.4 and RKA Client 1.9. The new report switches on only after Lovable's Control Room 0.4 update is applied, so this release is safe to install first.

- Sends Control Room the Steam and other launcher games on this PC, with Steam's own state for each (up to date, update waiting, updating, files missing), so Control Room can show which PCs have a game and which need an update. Sent when the list changes, or once a day.
- Everything else is as in 1.7.0.
