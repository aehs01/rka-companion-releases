# RKA Windows Companion v1.1.1-PILOT

Pilot build. Try it on RKA-TEST-LAPTOP before the other PCs, together with RKA Client 0.5.1.

## What's new

- **The arcade's website is always allowed** when Chrome and Edge are restricted: retroknightsarcade.com joins the fixed list of gaming sign-in, email-code and captcha sites. Retro Rewards members can open their rewards page, and RKA Client 0.5.1 can show it.
- Everything else is as in v1.1.0: four pages, no typed phrases, Task Manager block, LAN play, announcements through RKA Client, and the agent's Client status, Reset this PC, staff unlock and Call staff.

## Upgrading

Companion 1.0.9 or 1.1.0 can install this from Lovable & updates (Include pilot versions), or from Install from a ZIP file. The agent is upgraded at the same time. After installing, check that Lovable shows agent 1.1.1 for this PC. A restricted browser picks up the new allowed site after the guest signs out and back in, or after Apply changes.
