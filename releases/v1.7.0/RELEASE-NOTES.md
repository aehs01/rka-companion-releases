# RKA Windows Companion v1.7.0

Goes with Control Room 0.3 (retroknightsarcade.com/control-room) and RKA Client 1.8. Everything new switches on only after Lovable's Control Room 0.3 update is applied, so this release is safe to install first.

- Control Room can now set the four lockdown items that were only in this window: password changes, Lock on Ctrl+Alt+Del, Windows tips and pop-ups, and the guest's USB drives. Also Windows Update restarts (only after closing) and RKA Client as the guest's desktop, on or off.
- LAN games can be installed or removed from Control Room, and a session timer can be started on a PC (with RKA Client 1.8).
- One approved-sites list: sites approved in Control Room are passed to RKA Client 1.8 as well as Chrome and Edge.
- Power schedule: when it's set in Control Room, each PC shows a 5-minute notice and shuts down the set number of minutes after closing (never while staff have it unlocked).
- Reports which LAN games are installed and who is signed in to the intranet (with RKA Client 1.8).
- Fixed: Guest lockdown > Lock on Ctrl+Alt+Del > Block failed since 1.3.
- Updates page: Install from a ZIP and Open GitHub releases are labelled as backups for when automatic updates fail.
- Set the newest agent version: Control Room now approves new releases automatically.
