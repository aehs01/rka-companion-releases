# RKA Windows Companion v1.8.1

Goes with Control Room 0.6, RKA Client 1.9.1 and intranet theme 1.3.2. The new fields switch on only after Lovable's Control Room 0.6 update is applied, so this release is safe to install first.

- **Call staff says why.** When a customer presses one of the intranet's "Need a hand?" buttons, the call now carries the reason (a game won't start, controller or headset, signing in, a question about the PC, something else) and the LAN username of whoever is signed in. Control Room shows both on the call, and the Control Room app's alert says them. Both are re-checked here: an unknown reason is dropped and the username is cleaned and capped at 60 characters, and the call goes out either way.
- Everything else is as in 1.8.0.
