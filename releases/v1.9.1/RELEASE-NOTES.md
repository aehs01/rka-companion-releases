# RKA Windows Companion v1.9.1

Goes with RKA Client 2.2.0. Nothing changes in Lovable for this release.

- **Admin guest: an administrator account can be the guest.** On a busy day most games asked Windows for administrator access, and a standard guest can't answer that without the admin password, so the guest accounts were made administrators. Companion and Control Room then refused them. Now the guest picker lists administrator accounts too. The first change you make on one asks whether to make it this PC's admin guest. After that, every lockdown item, approved sites, Chrome auto-start, auto sign-in and Control Room's commands work on it as they do on a standard guest.
- **The lockdown comes back if someone removes it.** An administrator can undo the lockdown; a standard account can't. For an admin guest, Companion keeps a copy of its lockdown settings after every staff change (this window or Control Room). The background agent puts back anything missing or changed, about once a minute while the guest is signed in. Unlock everything clears the copy, so it never fights staff. The window shows how many times it put something back.
- **PCs already switched over are picked up by the agent.** If the guest became an administrator before this version, the agent makes it the admin guest only when it is the account Control Room's lockdown was approved for (only ever allowed for standard accounts) and the one Windows signs into automatically. Otherwise staff choose it in this window.
- **Companion won't open from the admin guest,** even when it's run as administrator there: sign into the staff account.
- **Set UAC to Never notify, don't turn it off.** With the slider at Never notify (the arcade PCs' setting), UAC stays on and administrators get admin access without any prompt, so games just start, and RKA Client keeps its lockdown. Turning UAC fully off (EnableLUA = 0, as some scripts do) makes RKA Client treat the admin guest as staff and drop its lockdown, stops Chrome auto-start and the intranet shortcut, and stops Store and Xbox apps.
- **Battlefield games start from Battlelog in Chrome or Edge too.** Battlelog's Join links (bf3lan:, bf4lan: and the ones for Hardline, Medal of Honor Warfighter, Bad Company 2 and Battlefield 1) are in the built-in list of game links the browsers may open, on every PC. RKA Client 2.2 opens Battlelog inside the app.
- Agent and scripts at 1.9.1.
